# Pull-up-Button

Навчальний проєкт для ESP32-S3 на Arduino framework і PlatformIO. Він демонструє читання зовнішньої кнопки з внутрішнім підтягуванням `INPUT_PULLUP`, читання вбудованої BOOT-кнопки та керування двома світлодіодами залежно від натиснутої кнопки.

## Що робить проєкт

Після запуску прошивка налаштовує GPIO 15 і GPIO 16 як виходи для червоного та синього світлодіодів, GPIO 14 як вхід із внутрішнім підтягуванням, а GPIO 0 — як вхід для BOOT-кнопки. У циклі вона зчитує обидві кнопки та виконує відповідну дію:

- **Зовнішню кнопку на GPIO 14 натиснуто:** червоний і синій світлодіоди блимають разом — 200 мс увімкнені, 200 мс вимкнені. У серійний порт виводиться повідомлення про натискання.
- **Натиснуто BOOT-кнопку на GPIO 0:** світлодіоди блимають почергово — спершу червоний, потім синій, по 1 секунді кожен. У серійний порт виводиться повідомлення про BOOT-кнопку.
- **Жодну кнопку не натиснуто:** обидва світлодіоди вимкнені, а в серійний порт виводиться повідомлення про відпущені кнопки.

Повідомлення доступні через серійний монітор на швидкості 115200 бод. Коли натиснуті обидві кнопки, пріоритет має зовнішня кнопка GPIO 14, оскільки вона перевіряється першою. Зчитування кнопок не має програмного усунення брязкоту контактів (debounce).

## Які задачі виконує та чого навчає

- Налаштовує цифрові входи та виходи ESP32-S3.
- Показує роботу `INPUT_PULLUP`: ненатиснута кнопка читається як `HIGH`, натиснута — як `LOW` (за підключення кнопки між GPIO 14 і GND).
- Зчитує стан зовнішньої кнопки та BOOT-кнопки.
- Керує двома світлодіодами за умовами `if/else` і створює різні світлові шаблони.
- Виводить стани й події в серійний порт для спостереження та налагодження.

## Обладнання та підключення

- ESP32-S3 DevKitM-1 або сумісна плата.
- Зовнішня кнопка між GPIO 14 і GND. Зовнішній підтягувальний резистор не потрібен: використовується внутрішній `INPUT_PULLUP`.
- Червоний світлодіод на GPIO 15 та синій світлодіод на GPIO 16; кожен підключити через струмообмежувальний резистор.
- Спільний GND для плати, кнопки та світлодіодів.
- BOOT-кнопка плати під'єднана до GPIO 0 на сумісних платах ESP32-S3.

Перевірте розпіновку своєї плати й електричні характеристики підключених компонентів. Якщо використовуються інші GPIO, змініть визначення `ledPin_red`, `ledPin_blue`, `buttonPin` і `buttonBoot` у `src/main.cpp`.

## Збірка, завантаження та моніторинг

Потрібні [Visual Studio Code](https://code.visualstudio.com/) із розширенням [PlatformIO IDE](https://platformio.org/install/ide?install=vscode) або PlatformIO Core. Під'єднайте плату USB-кабелем із передаванням даних і виконайте:

```sh
pio run
pio run --target upload
pio device monitor
```

Серійний монітор налаштований на 115200 бод. Якщо PlatformIO не визначає порт автоматично, задайте `upload_port` та/або `monitor_port` у `platformio.ini`.

## Налаштування PlatformIO

`platformio.ini` задає платформу Espressif32 `~6.8.1`, плату `esp32-s3-devkitm-1` та Arduino framework. Параметри пам'яті налаштовані для ESP32-S3-N16R8: 16 MB flash, 8 MB PSRAM і режим `qio_opi`. Переконайтеся, що ваша плата має таку конфігурацію, і за потреби змініть параметри.
